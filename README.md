# League Fixture Generator System

**Faculty of Computers and Information — Menoufia University**  
**Course:** System Analysis & Design (Second Year — 2026/2027)

---

## Project Description

The **League Fixture Generator System** is a web application designed to automate the creation and management of sports tournament schedules. It automatically generates fair, conflict-free match fixtures for different tournament formats (such as Round-Robin and Knockout) to prevent overlapping stadium bookings and scheduling errors. The system also tracks match results, points tables, and team standings in real time.
